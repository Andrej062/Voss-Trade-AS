# Voss Trade AS

Адаптивная страница продажи бань по предоставленному макету. HTML, CSS и JavaScript без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере. Для публикации загрузите `index.html`, `styles.css` и `script.js` на любой статический хостинг. Сайт пока не опубликован.

## Что заменить перед публикацией

- В `index.html` добавьте настоящие контакты в секцию `#kontakt` и уберите сообщение «Kontaktinformasjon kommer».
- Lun, Ro и Utsyn — примеры, а не подтверждённые товары. Замените названия и описания в `index.html` и `script.js` на реальные. После этого удалите пояснения об примерных моделях, в том числе в подвале и модальном окне.
- Для фотографий замените соответствующий `div.product-photo` на `<img class="product-photo" src="images/lun.jpg" alt="Описание конкретной бани" width="800" height="588" loading="lazy">`. Аналогично замените `div.hero-photo` на изображение с классом `hero-photo` (без `loading="lazy"`). Создайте папку `images` для файлов.
- Для изображений добавьте в конец `styles.css`: `.product-photo, .hero-photo { display: block; width: 100%; object-fit: cover; }`.

Шрифты загружаются из Google Fonts; без сети используются локальные Georgia и Arial. В проекте нет формы отправки, аналитики и серверной части. Кнопки моделей открывают подробности, навигация ведёт к разделам страницы.
